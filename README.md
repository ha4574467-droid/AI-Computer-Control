# 🤖 AI Hands-Free Computer Control System

An AI-powered computer vision and speech recognition system that allows users to control their PC using hand gestures and voice commands. Built using Python, MediaPipe, OpenCV, SpeechRecognition, and PySide6.

## ✨ Features
* 🖐️ **Gesture Mouse Control:** Control cursor movement smoothly using index finger pointing.
* 👌 **Pinch Click:** Natural pinch gesture to perform mouse clicks.
* 🎙️ **Voice Commands:** Execute system tasks (Open Browser, Notepad, Screenshots, Volume Control).
* 🛡️ **Safety Failsafe:** Fist-detection mechanism to immediately pause mouse control.
* 🖥️ **Modern GUI Dashboard:** PySide6 desktop UI to control the engine execution.
